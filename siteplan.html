Student Learning Hub

W05 Project: Website Planning Document

1. Site Name

Student Learning Hub

I chose this name because I want the website to be a place where students can find learning materials, improve their knowledge, and practise what they have learned in Mathematics and Computer Studies.

2. Site Purpose

Student Learning Hub is an educational website designed to help students improve their knowledge and skills in Mathematics and Computer Studies.

  • Provide Mathematics and Computer Studies lessons.
  • Share learning materials and explanations.
  • Provide interactive quizzes and activities.
  • Give instant feedback on quiz answers.
  • Support independent learning and practice.

3. Scenarios

  1. Where can I find simple Mathematics lessons to help me understand difficult topics?
  2. How can I practise Computer Studies and test my knowledge after studying?
  3. Are there quizzes to help me prepare for school examinations?
  4. Can I receive feedback after answering quiz questions?

4. Color Schema

Navy Blue: #14213D

Header, navigation, headings and footer.

Orange: #FCA311

Buttons, highlights and important links.

White: #FFFFFF

Page background and content areas.

Teal Green: #087F68

Correct answers and success messages.

5. Color Schema Use

This document uses the same colors planned for the website. Navy blue is used for the header and headings, orange for highlights, white for the background, and teal green for learning highlights.

These colors will create a clean and consistent learning environment.

6. Typography

Poppins

Poppins will be used for the main headings, page titles, and section headings.

Roboto

Roboto will be used for paragraphs, learning materials, descriptions, and general website text.
